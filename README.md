One museum label from the year 3000, in a single line of 127 characters: a group chat, where forty-seven humans gathered daily to decide nothing — which the curators of the year 3000 now believe was a religious ritual.

## Run it

```sh
python3 main.py
```

It validates the label (one line, 1–200 characters, plain ASCII English) and writes it to `/output/entry.txt`.
